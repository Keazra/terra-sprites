# Onlookers learn by watching

The M1 design still said onlookers learn nothing from what's done to another sprite, as slice 11d had left it ([#106](https://github.com/Keazra/terra-sprites/issues/106)). Slice 28 ([#146](https://github.com/Keazra/terra-sprites/issues/146)) settled and built learning by watching on 2026-10-14, in [the M2 design's §18](../m2-generations.md#18-learning-by-watching-slice-28), so the M1 design's sentences that said a sprite learns only from what happens to itself now point there. Found when #106 was closed as settled, on 2026-10-19 in round 1 of [#232](https://github.com/Keazra/terra-sprites/issues/232). Nothing in the game changes.

# Story mode and Lab mode

The game's two modes get their names: Story mode, the game as it's meant to be played, and Lab mode, for experiments. Settled with the owner on 2026-10-12, in round 4 of the ship's design pass ([#181](https://github.com/Keazra/terra-sprites/issues/181)), which also decided what each mode does on the ship. The same PR adds both to `CONTEXT.md`.
